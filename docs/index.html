One agent, or a team?

Does a small team of AI agents write more correct scientific code than one agent alone, with the same model and the same cap of model calls? Tested on three classic computational biology methods, scored on hidden tests.

Three arms, one budget

Same model (Claude Haiku 5.5, headless, no tools) and at most 6 model calls per run for every arm. Agents only write code; a harness runs every line.

Arm 1

One agent

Writes the solution and its own test, then fixes what failed, up to 5 times.

write→self-test→fix
Arm 2

Team + critic

A planner splits the work into 3 approaches, 3 implementers write in parallel, a critic writes its own checker, the best answer gets one fix.

plan→3 × write→critic→fix
Arm 3 · ablation

Team, no critic

Same planner and 3 implementers; each one's own self-test picks the best, up to 2 fixes.

plan→3 × write→fix

Three classic methods

Each spec is written from the original paper's math with 3 public examples. Hidden tests are scored against Biopython or a cross-checked reference, and no agent ever sees them.

01 · 60 hidden tests

Line up two DNA sequences

Local alignment with affine gaps. Smith & Waterman 1981, Gotoh 1982. Reference: Biopython PairwiseAligner.

02 · 40 hidden tests

Overlay two 3-D shapes

Optimal superposition RMSD. Kabsch 1976. Reference: Biopython SVDSuperimposer, mirror cases included.

03 · 50 hidden tests

Fold an RNA strand

Base-pair maximization. Nussinov et al. 1978. Reference: own DP, cross-checked by brute-force backtracking.

What went wrong, and what it shows

All logged as they happened in FAILURES.md.

  1. Real bugs only on affine gaps.2 of 9 single-agent first drafts scored 46/60 on alignment (for example 13 instead of 14). Both were fixed after the agent's own test failed.
  2. The critic raised only false alarms.One check called a point set a "cyclic axis permutation" with expected RMSD 0, but the points were not a rotation of each other: Biopython gives 1.16458704, exactly the code's answer. Both fix calls the critic triggered went to code that was already correct.
  3. Self-tests can be wrong too.In 3 of 5 single-agent fixes, the agent's own test expected the wrong value for code that was already correct.
  4. Slow drafts, rescued by selection.3 team drafts for alignment timed out on the hidden tests; picking among 3 siblings chose a correct, fast one.

On well-known methods, one agent with a test loop was enough.
Coordination only added cost.

Small test: one model, textbook algorithms it has likely seen, n = 3 per cell. Next: harder, less familiar methods where first drafts fail more often.
